# 📚 Included Interview Challenges

This repository contains implementations of several well-known technical interview problems:

### 🔹 **Island Perimeter**
Compute the perimeter of an island in a grid.

### 🔹 **Lockboxes**
Determine if all boxes can be opened with available keys.

### 🔹 **Log Parsing**
Parse HTTP logs and print aggregated statistics.

### 🔹 **Making Change**
Calculate minimum number of coins needed to reach a given amount.

### 🔹 **Minimum Operations**
Determine minimum operations to replicate characters using copy/paste logic.

### 🔹 **N Queens**
Place N queens on a chessboard without conflicts.

### 🔹 **Pascal’s Triangle**
Generate rows of Pascal’s triangle.

### 🔹 **Prime Game**
Determine the winner of a number-based prime game.

### 🔹 **Rotate 2D Matrix**
Rotate a matrix 90 degrees in place.

### 🔹 **UTF-8 Validation**
Verify if a sequence of bytes is valid UTF-8.

### 🔹 **Star Wars API**
Interacting with SWAPI to retrieve character information.
